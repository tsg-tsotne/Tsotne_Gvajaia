# ცოტნე გვაჯაია — პორტფოლიო

ქართულენოვანი სტატიკური საიტი: RoboSpark და STEAM კლუბები, პროექტები, სიახლეები და ვიდეოგაკვეთილები.

## გაშვება

საქაღალდე გაუშვით სტატიკური HTTP სერვერით. მაგალითად, Python-ის არსებობისას:

```sh
python -m http.server 4173
```

შემდეგ გახსენით http://localhost:4173/ . ძიება HTTP სერვერს საჭიროებს.

## ფაილები

- `index.html` — მთავარი გვერდი
- `news.html` — კლუბის სიახლეები
- `stem.html`, `robospark.html` — კლუბები
- `tutorials.html`, `tutorials.js` — ვიდეოგაკვეთილები
- `app.js`, `style.css` — საერთო ფუნქციები და დიზაინი
- `assets/` — ფოტოები, ლოგოები, ვიდეოები და სიახლეების მონაცემები

პროექტებს ცალკე HTML გვერდები აქვთ. სიახლეების HTML და `assets/news/posts.json` ერთად უნდა განახლდეს. JSON-ის ცვლილება ავტომატურად არ ცვლის გვერდს.

გარე სერვისებია Google Fonts, YouTube და Facebook-ის ბმულები. გამოქვეყნების ავტომატური პროცესი არ არის ჩართული.
